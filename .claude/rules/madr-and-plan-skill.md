# Load the writing-madr-and-plans skill for MADR and plan requests

Whenever the user asks for an MADR and a plan, load the
`writing-madr-and-plans` skill first and follow it for authoring, naming
(`NNNN-MADR-*` / `NNNN-PLAN-*`), and review. This applies both to writing a
fresh pair and to amending an existing one.

The operational copy of this rule is `AGENTS.md` (see the "MADR and PLAN before
mutating work" section). Honour both; do not fork a third workflow.
