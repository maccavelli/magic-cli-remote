# PLAN 0171 (second) — Agents run the disclosure guard before a push is asked for

Associated MADR: [0171-MADR-redact-published-identifiers-so-pushes-pass-the-disclosure-guard.md](0171-MADR-redact-published-identifiers-so-pushes-pass-the-disclosure-guard.md),
its amendment of 2026-10-22, decisions D6–D8.

## Goal

AGENTS.md tells every agent to run the guard over the outgoing commits before asking for a push,
never to bypass it, and to record identifier scans without quoting identifiers. The command it
gives is proven to pass a clean push and to refuse a dirty one.

## Scope

**Files:** `AGENTS.md`, its section "MADR and PLAN before mutating work", subsection "Host
identifiers never appear in records"; this plan and the MADR's amendment; and `docs/README.md`'s
row for this plan, regenerated by `scripts/check_records.py --write-index`.

- **Not in scope:**
  - the per-agent pointer files and a Make target, which the owner did not choose;
  - the guard itself and its deny list, which are the dotfiles' (their MADR 0010);
  - redacting anything in the tree. The guard passes today.

## Implementation Steps

### G1 — AGENTS.md (D6–D8)

1. Under "Host identifiers never appear in records", after its paragraph, add three bullets:
   - **D8:** record an identifier scan by what was scanned for, never the value.
   - **D6:** before asking the owner to push, and before any push the owner asks for, run the
     guard over the outgoing commits, with the MADR's command for `master`. Exit 1 stops the
     push; report it as counts by placeholder and by file, and fix it as MADR 0171 does.
   - **D7:** never `--no-verify`.
2. The wording follows go-llmprovider-sdk's AGENTS.md, with `master` for `main`. The same bullet
   cites [0171-MADR-redact-published-identifiers-so-pushes-pass-the-disclosure-guard.md](0171-MADR-redact-published-identifiers-so-pushes-pass-the-disclosure-guard.md).

### G2 — Prove the command, on a scratch clone

The command is run exactly as AGENTS.md prints it, by a script that reads it from AGENTS.md and
hands it to `bash -c` in a scratch clone.

1. **Setup.** The clone's origin URL is set to this repository's GitHub URL, with no fetch, and
   one commit is made there that origin does not have.
2. **Clean:** with the owner's deny list, exit 0.
3. **Planted:** with `DISCLOSURE_DENY` pointing at a temporary list whose one rule matches a
   string committed in the clone, exit 1, naming the planted file. This is the gate seen to fail.
4. Nothing is pushed: the clone has no credentials, and the command only reads.

### G3 — Gates

- markdownlint on `AGENTS.md`, under the repository's config; the records are linted too.
- `scripts/check_records.py --check`.
- An identifier scan of the changed files, recorded as D8 says.
- The guard over the outgoing commits, as G1 requires, before the push is asked for.
