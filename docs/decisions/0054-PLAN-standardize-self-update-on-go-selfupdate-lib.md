# Implement standardizing self-update on `go-selfupdate-lib`

Associated MADR: [0054-MADR-standardize-self-update-on-go-selfupdate-lib.md](0054-MADR-standardize-self-update-on-go-selfupdate-lib.md)

This PLAN has one phase, R1, which is documentation only. The MADR is `proposed`. R1 produces the
evidence report the owner asked for, so the MADR can be reviewed against the current library and
tree. The source phases the MADR's "Implementation Plan" note lists are **not** planned here. They
are added by a later amendment of this PLAN, after the MADR is accepted and the report reviewed.

## Goal

`docs/reports/0054-REPORT-go-selfupdate-lib-full-adoption-assessment.md` says exactly what full
adoption of `go-selfupdate-lib` requires. Full adoption moves self-update, release building and
publishing, service lifecycles, and installers out of `magic-cli-remote` and into the library. A
maintainer reading the report can review MADR 0054 without repeating the investigation.

### S8 step 1, replaced (A1, A2, A4)

S8's Scope adds `internal/admin/`, `internal/daemon/` (the shutdown wiring), `internal/cli/serve.go`
and `internal/relay/` (the probe's address and TLS resolution, read only), with their tests.

- **1a. `mcremote`'s probe is the admin socket's `ping` (A1).**
  - The `Options.Probe` of each `mcremote` backend (`systemd`, `launchd`, `taskscheduler`) is a
    `service.HealthProbe` that calls `admin.Call(<the instance's admin socket>, admin.Request{Op:
    admin.OpPing})`.
  - It returns `Health{Ready: true}` only when the call succeeds and `Response.OK` is true. A
    failed call is returned as an error, which `PollHealthy` keeps.
  - The socket path comes from the same configuration resolution `pair` uses for its `ping`
    (`internal/cli/pair.go:36`).
- **1b. The admin socket gains a shutdown operation (A2).**
  - `internal/admin` adds an operation constant beside `OpPing` and dispatches it.
  - On receiving it, the daemon cancels the same context its shutdown signals cancel
    (`internal/cli/serve.go:46`), so it runs exactly the shutdown path it runs on a signal.
  - The reply is sent before the shutdown begins.

### S5e, 2026-10-19 — staged for the owner's commit

**Starting point.** The owner committed S5d and said "proceed".

**What S5e changed:**

- **`internal/cli/service/uninstall.go` (new).** `Uninstall` is `install.sh`'s `do_uninstall`
  (`:960-997`), with its ownership rule:
  - **What it looks at.** For `mcremote` and `mcrelay`, it looks under the recorded unit name and
    the product name. It does this on every service manager the OS has: systemd, runit, s6 and
    OpenRC user services on Linux; the LaunchAgent on macOS; the task, by product name, on Windows.
  - **What it removes.** A definition whose program is in the folder of the binary running the
    command, symlinks resolved, is stopped, disabled and deleted through the existing
    `removeSystemd`, `removeScript`, `removeLaunchdAgent` and `removeSchtasks`. Its unit-name and
    backend records go with it when its name is the recorded one.
  - **What it leaves.** A definition that runs another folder's program is reported and left, so
    two installs do not remove each other. So is one whose program cannot be read, such as a
    hand-written one.
  - **Where the program is read from.** systemd's `ExecStart`, the recovered script or plist, or
    the task's exported `Command`.
  - **Failures.** A removal that fails is reported, the rest still run, and the command fails.
  - **Output.** `PrintUninstallResult` prints `removed:`, `left:` and `failed:` lines; with
    nothing found, it says "no service definition of mcremote or mcrelay was found".
- **`internal/cli/setup_service.go` and `internal/relay/cli.go`:** `--uninstall` on both commands,
  refused with `--refresh` or `--remove`.

**A decision inside the PLAN's words.** `install.sh` removed a definition whose program it could
not read, treating it as its own (`svc_targets_install_dir`, `:387-392`). The PLAN's step says
"if the definition's program is in the same folder", and an unreadable one is not known to be.
So it is left and reported.
